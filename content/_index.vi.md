# Báo cáo thực tập - EduFlow Platform

EduFlow là nền tảng quản lý và phân phối khóa học trực tuyến, phục vụ ba nhóm người dùng: **học viên**, **giảng viên** và **quản trị viên**. Hệ thống tách thành ứng dụng giao diện Spring Boot/Thymeleaf và REST API Spring Boot, sử dụng MySQL, JWT, VNPay, Docker, Terraform và Amazon ECS Fargate.
